  ---   ##  ⚙  Configuration  &  Routing  Flow   ###  Request  Lifecycle  Example:  `stag.aivory.id`   1.  __User__  $\rightarrow$  Requests  `https://stag.aivory.id`.  2.  __Traefik__  $\rightarrow$  Matches  `Host(`stag.aivory.id`)`,  terminates  SSL,  and  forwards  to  
`stag-frontend:80`.
 3.  __Nginx  (stag-frontend)__  $\rightarrow$  Serves  `index.html`  from  `/usr/share/nginx/html`.  4.  __Browser__  $\rightarrow$  Executes  `app.js`,  which  makes  API  calls  to  `api.aivory.id`.  5.  __Traefik__  $\rightarrow$  Routes  `api.aivory.id`  to  the  __VPS  Bridge__.  6.  __VPS  Bridge__  $\rightarrow$  Validates  request  $\rightarrow$  Forwards  to  __ZeroClaw__  or  
__n8n__.
  ###  Network  Summary   -  __External  Network__:  Public  Internet  $\rightarrow$  Traefik  (Ports  80,  443).  -  __Internal  Network__:  `avry-admin-dashboard_app-network`  (All  containers  communicate  here  
via
 
service
 
names).
